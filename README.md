# Recipes App

A SPA application for displaying a list of recipes and detailed information about each recipe.
The data is fetched from the DummyJSON API.

## Features
- React 19 with hooks
- React Router v7 for routing
- Redux Toolkit for state management
- RTK Query for caching and working with APIs
- Webpack 5 for bundling (without Create React App)
- Responsive design for mobile and desktop

## Pages
- Home '/',
- Recipe '/recipe/:id',
- Login '/login',
- Register '/register',
- Favorites '/favorites'

## Technical Features
- Fetch recipes list from API
- View recipe details
- Adding recipes in favorites list
- Searching recipes by name and tags

## Installation
